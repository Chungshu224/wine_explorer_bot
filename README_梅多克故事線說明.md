# 梅多克故事線《六十一個名字》說明

## 這是什麼

波爾多的第一條故事線,campaign id 是 `medoc_line`,已經合併進
`story_data.json`(現在總共 15 條故事線)。因為 `major_region` 標成
`"波爾多 Bordeaux"`,跟布根地那 14 條(`major_region: "布根地 Bourgogne"`)
不一樣,`/campaigns` 選單會**第一次真正出現大產區選單**(之前只有布根地
一個大產區時,程式會自動跳過這層,直接顯示次產區列表)。

## 角色與敘事骨架

角色是 Antoine Lasserre,康特納克(Cantenac,瑪歌村內的一個小地名)一間
虛構酒莊的調配師(maître de chai)。核心敘事張力延續你在架構規劃時定的
方向:

> 調配是每年都要重新決定的藝術,分級卻一百七十年只改過一次

六個章節分三層,結構跟布根地那些故事線完全對齊(2 核心章節、2 知識驛站、
2 中繼站):

| 章節 | 層級 | 需要印記 | 知識重點 |
|---|---|---|---|
| 第一章:調配室的第一課 | 核心章節 | 無 | 卡本內蘇維濃調配邏輯、砂礫地排水 |
| 驛站:1855分級的誕生 | 知識驛站 | 無 | 1855分級是市場價格排名,不是盲品/土壤調查 |
| 第二章:六十一分之一的例外 | 核心章節 | 調配邏輯基礎 | 1973木桐堡升級,分級近乎凍結的原因 |
| 驛站:四座村莊,四種性格 | 知識驛站 | 無 | 瑪歌/波雅克/聖朱利安/聖艾斯泰夫風格差異 |
| 支線:名單之外的酒莊 | 中繼站 | 1855分級邏輯 | 中級酒莊制度(Cru Bourgeois),持續修訂的對照組 |
| 支線:調配師的抉擇 | 中繼站 | 調配邏輯基礎、梅多克村莊風格差異 | 實際調配決策情境,整合前面所有知識點 |

最後一章刻意設計成「情境判斷題」而不是單純知識問答——玩家要根據
「當年氣候偏涼濕、卡本內成熟度不足」這個具體情境,判斷該怎麼調整調配
比例,呼應第一章教過的「調配是每年重新做的判斷」這個核心主題,首尾
呼應。

## 技術面,直接套用你先前踩過的坑

- Quiz 選項從第一天就是「完整敘述放題目本文,按鈕只留 A/B/C」的格式。
- 章節結尾沒有寫死「下一章尚未解鎖」,兩個核心章節結尾都是直接連到
  下一章(因為印記在同一章已經拿到,一定解鎖),其中一個章節結尾用
  「輸入 /chapters 看看還有哪些支線」這種通用提示,不會過期。
- callback_data 沿用 bot.py 原本就有的索引機制,新故事線的內容完全不用
  改 `bot.py` 本身。
